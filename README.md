# قبل الرفع على GitHub

الفيديوهات بقت متضمّنة مباشرة كـ YouTube embed (مفيش ملفات فيديو مطلوبة).

باقي بس الصور — حط الملفات دي (jpg) جوه فولدر `assets/img` بنفس الأسماء:
work-1.jpg, work-2.jpg, work-3.jpg, work-4.jpg, work-5.jpg, work-6.jpg

لو عايز تغيّر الأسماء أو تزوّد صور، افتح `index.html` وعدّل قسم `id="work"`.

بعد كده ارفع الفولدر كله (`index.html` + `assets`) على GitHub، وبعدها Vercel.
